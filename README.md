# Emulator's Emulator

### One APK. Endless EXEs. One universe.

**Emulator's Emulator** is an ambitious Android emulator project by [Emulator-ENG](https://github.com/Emulator-ENG).

The goal is to create a universal Android application capable of running Windows `.exe` applications and games directly on Android devices.

## 🚀 Project Goals

- [ ] Create a native Android APK
- [ ] Build a futuristic game library
- [ ] Import Windows `.exe` files
- [ ] Develop automatic game detection
- [ ] Implement Windows application compatibility
- [ ] Support modern Windows games
- [ ] Optimize performance for lower-end Android devices
- [ ] Create a simple, touch-friendly interface
- [ ] Investigate compatibility with the BLOODMONEY Trilogy

**Platform**

- Android
- ARM64 devices
- Android 10 and newer (target)

**Development**

This project is currently in its early access.

The application will require a compatible execution engine to run Windows EXE files. File importing and the user interface alone do not provide Windows compatibility.

**!Disclaimer!**

Emulator's Emulator is an experimental project. Compatibility with Windows applications and games is not guaranteed.

The long-term vision is to make Windows software more accessible on Android through a simple, unified emulator experience.
